# Task Workflow

يُستخدم هذا المجلد لتسليم مهمة واحدة واضحة إلى أي Agent يعمل على المشروع.

## طريقة الاستخدام

1. اكتب وصف المهمة الكامل داخل `tasks/CURRENT_TASK.md`.
2. ضمّن النطاق، القيود، أوامر التحقق، وسياسة Git المطلوبة.
3. اطلب من Agent: "نفذ المهمة الحالية".
4. سيقرأ Agent ملف المهمة كاملًا ويلتزم بتعليمات `AGENTS.md`.
5. تابع تقدم التنفيذ والنتيجة النهائية في `reports/LATEST_REPORT.md`.

## قواعد مهمة

- يحتوي `CURRENT_TASK.md` على مهمة واحدة فقط في كل مرة.
- لا يغيّر Agent محتوى `CURRENT_TASK.md` أثناء التنفيذ.
- يجب ألا يحتوي ملف المهمة على أسرار أو tokens أو بيانات شخصية.
- لا يعني طلب تنفيذ المهمة السماح تلقائيًا بـ`commit` أو `push`؛ يجب أن تنص المهمة على ذلك صراحة.
