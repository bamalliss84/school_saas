# خطة إكمال المشروع حتى الإطلاق

آخر تحديث: 2026-11-15. الفرع الحالي: `release/1.1-dev`.

## ما تم

- الإصدار 1.0: لوحة إدارة المدرسة كاملة، وفيها الطلاب والمعلمون وأولياء الأمور والفصول والجداول والحضور والواجبات والاختبارات والرسائل والإعلانات والتقارير والاستيراد والتصدير بـ Excel.
- الإصدار 1.0.1: إعدادات تشغيل آمنة، واستعادة كلمة المرور بالبريد، وتغيير كلمة المرور (في الويب والتطبيقات)، وملفات Docker والنشر، والنسخ الاحتياطي.
- الإصدار 1.1:
  - الرسوم المدرسية مع الأقساط والدفعات اليدوية والإيصالات والتذكيرات.
  - اشتراكات المدارس في المنصة ولوحة مالك المنصة.
  - تنبيه الرسوم وصفحتها في تطبيق ولي الأمر.
  - حصر مدير المنصة داخل المدرسة المختارة في تقارير الحضور.
- التطبيقات: ولي الأمر والطالب والمعلم، وفيها الجدول والحضور والواجبات والنتائج والرسائل والإعلانات، وتعمل بدون إنترنت من آخر بيانات محفوظة.

## المتبقي

### المرحلة 1: أنفذها بنفسي (لا تحتاج منك شيئًا)
1. أمر لتعبئة بيانات تجريبية كاملة: مدرسة، طلاب، معلمون، أولياء أمور، رسوم، اشتراك.
2. فحص يدوي لكل شاشات الويب بالمتصفح باستخدام هذه البيانات، وإصلاح ما يظهر.
3. ~~مراسلة ولي الأمر لمعلم ابنه~~ (تم في تطبيق ولي الأمر). المتبقي: أن يبدأ المعلم المحادثة من تطبيقه.
4. مراجعة تجربة الاستخدام: نفس الألوان والمسافات ورسائل الخطأ والحالات الفارغة، وإمكانية الوصول، في الويب والتطبيقات.
5. إزالة بقية الاعتماد القديم على `request.user.school/role` في الشاشات القديمة، مع اختبارات عزل المدارس.
6. جدولة المهام اليومية (`run_billing_jobs`) والنسخ الاحتياطي داخل `docker-compose`.
7. مراقبة الأخطاء (Sentry أو ما يماثله)، وتعمل فقط إذا وُضع المفتاح في الإعدادات.
8. تجهيز التطبيق للمتاجر: اسم الحزمة النهائي، والأيقونة، وشاشة البداية، وإعداد التوقيع (بدون المفاتيح).

### المرحلة 2: تحتاج قرارًا أو حسابًا منك
| البند | المطلوب منك |
|---|---|
| السيرفر والدومين | شراء سيرفر (VPS) ودومين، ثم أنفذ النشر بالدليل `docs/DEPLOYMENT.md` |
| البريد | حساب SMTP لإرسال رسائل استعادة كلمة المرور |
| الإشعارات الفورية | إنشاء مشروع Firebase، ثم أربطه أنا |
| المتاجر | حساب Google Play، وApple Developer إن أردت iOS |
| النصوص القانونية | مراجعة صفحتي الشروط والخصوصية من مختص |
| اسم المنتج وشعاره | الاسم النهائي والشعار |

### المرحلة 3: الإصدار 1.2 (بعد الإطلاق)
- ربط بوابة دفع إلكتروني للرسوم والاشتراكات.
- إشعارات فورية كاملة في التطبيقات.

## قواعد العمل
- كل مرحلة تنتهي بفحص كامل: اختبارات الخادم والويب والتطبيقات.
- بعد كل مرحلة commit وpush إلى فرع التطوير.
- الدمج في `main` فقط بموافقة صريحة.
