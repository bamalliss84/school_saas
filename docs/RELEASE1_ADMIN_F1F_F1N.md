## معايير مشتركة لكل مرحلة

- **S1 عزل المدارس:** كل قراءة وكتابة محصورة في `request.active_school`، والمعرّف الأجنبي يرجع 404 أو 403 دون كشف بيانات.
- **S2 الدور:** عمليات الإدارة لمدير المدرسة أو Super Admin فقط، والمعلم والطالب وولي الأمر يُرفضون أو يُحصرون في نطاقهم.
- **قرار Super Admin في الحضور (2026-11-13):** يبقى سلوك 1.0 الحالي (رؤية حضور كل المدارس، وقراءة `attendance/daily/` للحقول القديمة) كما هو وموثقًا باختبار. في 1.1 تُنقل هذه الرؤية إلى لوحة مالك المنصة، ويُحصر Super Admin داخل الـ API المدرسية في Active Context مثل غيره.
- **S3 السياق التاريخي:** القراءة مسموحة حيث يُسمح بها، وكل كتابة ترجع 403 من الخادم، والويب يخفي أدوات التعديل.
- **S4 مصدر السلطة:** `active_membership/active_school/active_role/active_academic_year` فقط.
- **S5 الاختبارات:** اختبارات Backend تغطي S1 إلى S3، واختبارات Web للتدفق الأساسي ولوضع القراءة فقط.
- **S6 البوابات:** نجاح `check` و`makemigrations --check` و`test core`، ونجاح Web `typecheck/lint/test/build`.

نجاح الاختبارات وحده لا يثبت اكتمال المرحلة؛ يجب ربط كل معيار بدليل من اختبار أو مسار كود.

## F1F — الجدول المدرسي

| المعرف | المعيار |
|---|---|
| F1F-1 | تهيئة أيام العمل (`timetable/config/`) والفترات بما فيها الاستراحات (`timetable/periods/` و`periods/bulk/`)، مع حماية الفترات المستخدمة. |
| F1F-2 | اختيار الصف والشعبة وعرض الشبكة (أيام × فترات)، والاستراحة تظهر صفًا غير تدريسي. |
| F1F-3 | إضافة حصة واستبدالها وحذفها عبر `assignment-options` المتوافقة فقط (معلم — مادة). |
| F1F-4 | تعارضات المعلم والصف/الشعبة تظهر أخطاءً واضحة، ولا يحدث حفظ جزئي (`bulk/` و`validate/`). |
| F1F-5 | نسخ يوم أو أسبوع مع `clear_target` صريح. |
| F1F-6 | السياق التاريخي للقراءة فقط مع إخفاء أدوات التعديل. |

## F1J — الاكتشاف الآمن

| المعرف | المعيار |
|---|---|
| F1J-1 | `GET communication/recipient-options/?student_id=` يرجع للمعلم أولياء أمور طالب في شعبة يدرّسها حاليًا فقط. |
| F1J-2 | يرجع لولي الأمر معلمي ابنه المرتبط به في السنة النشطة فقط. |
| F1J-3 | يرجع `recipient_ref` موقّعًا وقصير الصلاحية بدل معرّفات العضوية الخام. |
| F1J-4 | الرفض في الحالات التالية: دور غير مخول، طالب خارج النطاق، مدرسة أجنبية، عضوية ولي أمر غير نشطة. |
| F1J-5 | بدء محادثة معلم ← ولي أمر يتطلب `recipient_ref` صالحًا يطابق المدرسة والطالب والتكليف، ويُرفض المرجع المعدّل أو المنتهي أو الأجنبي. |
| F1J-6 | يستطيع المعلم اختيار التكليف المحدد إذا كان يدرّس أكثر من مادة للشعبة نفسها. |
