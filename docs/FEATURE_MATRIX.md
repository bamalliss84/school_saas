## حدود مثبتة

- الترقيم الحالي للموبايل هو M2.5 للواجبات، وM2.6 للاختبارات والنتائج،
  وM2.7 للاتصالات. لا يُستخدم الترقيم القديم الذي كان يفصل Submissions.
- يدعم Teacher Mobile الإشعارات ودورة حياة الإعلانات ومحادثات
  Teacher → Student. إنشاء Teacher → Parent **مؤجل** حتى يتوفر اكتشاف آمن
  لمستلمي أولياء الأمور/الأوصياء ضمن نطاق المعلم؛ معرفات العضوية الخام ليست حلًا.
- إصلاحات ترشيح نتائج الطالب وعرضها مدمجة، وتبقى الرؤية مقيدة بدلالات
  الاعتماد والنشر في التنفيذ الحالي.
- دمج W10 وإصلاح النشر التزايدي لا يعني اكتمال School Admin Web Portal V1؛
  البوابة ما زالت **قيد العمل**.
- مراجعة/إعادة تصميم UI/UX للموبايل والويب **مخططة** كمسار Release 1.0 بعد
  الاستقرار الوظيفي، مع الحفاظ على قواعد العمل وعقود API المعتمدة.
